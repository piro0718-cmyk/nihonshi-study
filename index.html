1｜鎌倉末期から戦国時代へ

元寇・室町の外交・応仁の乱

1 / 4

最初のポイントは、外国との戦争が鎌倉幕府の衰退に影響し、室町幕府の弱体化が戦国時代を招いたという大きな因果関係です。

元寇→御家人の困窮→鎌倉幕府滅亡→室町幕府→応仁の乱→戦国時代

1274・1281 元寇（蒙古襲来）

モンゴル帝国を基礎に中国を支配した元の皇帝フビライ＝ハンは、日本に服属を求めた。鎌倉幕府が拒むと、元は高麗の軍勢・船なども用いて九州北部へ来襲した。

1274年文永の役。博多湾岸などで戦闘。
1281年弘安の役。幕府は博多湾岸に石築地（防塁）を築いて備えた。暴風雨などもあり元軍は撤退。
なぜ幕府が弱まった？ 防衛戦なので新しい領地が得られず、命をかけて戦った御家人に十分な恩賞を与えにくかった。御家人の借金・所領分割も進み、幕府は1297年に永仁の徳政令を出したが、立て直しは難しかった。

1333〜1392 鎌倉幕府から室町幕府へ

  1. 1333年　後醍醐天皇側についた足利尊氏・新田義貞らにより鎌倉幕府が滅亡。
  2. 建武の新政　後醍醐天皇が天皇中心の政治を進めるが、武士の不満が高まる。
  3. 1338年　足利尊氏が征夷大将軍となり、室町幕府が成立。
  4. 1392年　3代将軍足利義満の時代に南北朝が統一。

14〜15世紀 東アジアとの三つの窓口

明
足利義満が1404年に日明貿易（勘合貿易）を開始。勘合で正式な貿易船と倭寇を区別。日本は銅・硫黄・刀剣などを輸出し、銅銭・生糸・絹織物などを輸入した。
朝鮮
対馬の宗氏が貿易や外交で重要な役割を担った。
琉球
琉球王国は日本・中国・東南アジアを結ぶ中継貿易で繁栄した。

1467〜1477 応仁の乱と戦国大名

8代将軍足利義政の後継問題、畠山氏・斯波氏の家督争い、有力守護大名の対立などが重なり、細川勝元と山名宗全を中心とする戦乱が京都で続いた。

幕府と守護大名の権威が低下し、実力ある者が上位者を倒す下剋上が進む。各地の戦国大名は、家臣統制のための分国法、城下町、検地などで領国を直接支配した。

つながり：政治が分裂したからこそ、のちに信長・秀吉・家康が「全国統一」を目指す。

次の時代への伏線｜村と宗教勢力も力をもつ

惣村と土一揆
農民たちは自治的な村（惣村）をつくり、徳政などを求めて土一揆を起こした。1428年の正長の土一揆が代表例。

山城国一揆
1485年、山城の国人らが対立する守護大名の軍を国外へ退去させ、自治を行った。

加賀の一向一揆
1488年、一向宗（浄土真宗）の門徒らが守護を倒し、約1世紀にわたり支配。のちに信長が石山本願寺・一向一揆と対立する背景になる。

このページの一文： 元寇後の御家人の不満が鎌倉幕府を弱め、室町幕府も応仁の乱で権威を失い、各地の戦国大名が争う時代になった。

2｜ヨーロッパ人の来航と統一の開始

鉄砲・キリスト教と織田信長

2 / 4

鉄砲と南蛮貿易は、戦国大名の戦い方・経済・宗教政策を変えました。信長は新しい技術と商業を利用し、室町幕府を終わらせます。

1543 鉄砲伝来

ポルトガル人を乗せた中国船が種子島に漂着し、火縄銃が伝わった。鉄砲は堺・国友などで国産化され、集団運用により戦い方を変え、鉄砲に対応した城づくりにも影響した。

覚え方：「ポルトガル船」と単純化せず、ポルトガル人が乗った中国船。1543年＝鉄砲、1549年＝キリスト教。

1549 キリスト教伝来

イエズス会のフランシスコ＝ザビエルが鹿児島に来航。宣教師は学校・病院なども設けて布教し、大名の中には貿易上の利益を期待して布教を認め、自ら入信するキリシタン大名も現れた。

改宗の背景は一つではない。宣教師との出会いによる信仰、南蛮貿易を領国へ引き寄せる実利、周辺大名との争いや領国支配が重なった。本人の信仰心と政治・経済上のねらいを、単純な二者択一にしないこと。

キリシタン大名｜なぜ入信し、その後どうなった？

共通する背景：ポルトガル船は中国産生糸などを運び、宣教師は貿易の仲介にも関わった。そのため布教の保護は、信仰だけでなく港・貿易・武器や海外情報の獲得とも結びついた。一方、禁教が強まると、大名は棄教・改易・処罰・国外追放など異なる道をたどった。

大友宗麟（フランシスコ）豊後。早くから宣教師と南蛮貿易を保護し、1578年に受洗。大村・有馬と使節を派遣した。島津氏との戦いで勢力を弱め、秀吉に救援を求め、1587年に死去。
大村純忠（バルトロメオ）肥前。1563年、日本初のキリシタン大名となる。横瀬浦・長崎を開き、貿易の定着と領地防衛も意識して宣教師を保護。1587年に死去し、子の喜前はのちに禁教へ転じた。
有馬晴信（プロタジオ）肥前。龍造寺氏の圧迫を受けるなか、1580年に受洗。宣教師・南蛮貿易を保護し、セミナリヨも置いた。のち岡本大八事件に連座し、1612年に所領没収・処罰。
高山右近（ジュスト）摂津。父の影響で少年期に受洗し、強い信仰をもった。1587年、秀吉の棄教命令を拒んで領地を失う。1614年の禁教でマニラへ追放され、翌年に死去。
小西行長肥後南部。秀吉に仕えたキリシタン大名で、領内の布教を保護した。朝鮮出兵では第一軍を率い、関ヶ原の戦いでは西軍に属して敗れ、1600年に処刑された。

使節を送った3大名：大友宗麟・大村純忠・有馬晴信。大名の選択は家臣・領民や寺社にも及び、禁教後には棄教する者、信仰を隠して続ける者、処罰される者が生まれた。

天正遣欧少年使節｜4人の名前と帰国後

マンショ・ミゲル・マルチノ・ジュリアンは、使節当時からの洗礼名。4人は有馬のセミナリヨ（神学校）で学び、1582年に出発、ローマ教皇らに謁見し、1590年に帰国した。1591年にイエズス会へ入会したが、その後の道は分かれた。

正使　伊東マンショ大友宗麟の名代。1608年に司祭となり、長崎のコレジヨで活動。1612年に病死。
正使　千々石ミゲル大村純忠・有馬晴信の名代。1601年までにイエズス会を脱会し、千々石清左衛門と名乗って大村藩に仕えた。
副使　原マルチノ1608年に司祭。語学・翻訳にも力を発揮。1614年にマカオへ追放され、1629年に死去。
副使　中浦ジュリアン1608年に司祭。禁教下でも潜伏して布教を続け、1633年に長崎で殉教。

16世紀 南蛮貿易と南蛮文化

日本から銀・刀剣・漆器などを輸出し、中国産の生糸・絹織物、鉄砲、火薬原料などを輸入。平戸・豊後府内・長崎などが栄え、活版印刷・西洋画、パン・カステラ・カルタなども伝わった。

1560〜1582 信長の統一事業

1560桶狭間の戦いで今川義元を破る

1568足利義昭を奉じて京都に入る

1570姉川の戦いで浅井・朝倉軍と戦う

1571比叡山延暦寺を焼き打ち

1573義昭を追放し室町幕府を滅ぼす

1575長篠の戦いで鉄砲を有効に使用

1576安土城の築城を始める

1580石山本願寺との戦いが終わる

1582本能寺の変で自害

経済 楽市・楽座、関所の廃止、城下町の整備で商工業と流通を活性化。

宗教・外交 延暦寺・一向一揆・石山本願寺など、独自の武力・土地・経済力をもち統一に抵抗する仏教勢力と対立。南蛮貿易を重視し、仏教勢力への対抗にもなるキリスト教の布教を保護した。

このページの一文： 鉄砲・南蛮貿易・キリスト教が戦国社会を変え、信長は経済力と軍事力を伸ばして統一を進めたが、本能寺の変で途中に倒れた。

3｜信長から秀吉、秀吉から家康へ

豊臣秀吉・徳川家康の全国統一

3 / 4

この時代は「引継ぎ」が重要です。秀吉は本能寺の変への素早い対応で主導権を握り、家康は豊臣政権内の対立を利用して全国支配を固めました。

周辺エピソード｜中国大返しで秀吉が抜け出す

  1. 1582年6月2日本能寺の変。明智光秀が信長を討つ。
  2. 知らせを受ける秀吉は備中高松城を攻め、中国地方の毛利氏と戦っていた。
  3. 毛利氏と講和急いで戦いを終え、軍を率いて畿内へ戻る。これが中国大返し。
  4. 6月13日山崎の戦いで光秀を破り、「信長の仇を討った」立場を得る。

1582〜1590 秀吉が全国統一するまで

  1. 清洲会議で織田家の後継や領地配分を協議。信長の孫・三法師を後継に推す。
  2. 1583年 賤ヶ岳の戦いで柴田勝家を破る。お市の三人の娘は秀吉に引き取られた。
  3. 1584年 小牧・長久手の戦いで徳川家康・織田信雄と戦う。のちに講和し、家康を臣従させる。
  4. 1585年 関白、翌年に太政大臣となり豊臣姓を受ける。
  5. 1587年 九州を平定。1590年 小田原の北条氏を倒し、奥州も服属させて全国統一。

国内政策 太閤検地と刀狩

太閤検地：全国で田畑を測量し、石盛・石高を定め、耕作者を検地帳に登録。一地一作人の原則で年貢負担者を明確にした。

刀狩令（1588）：農民から刀や鉄砲などを取り上げ、一揆を防ぎ、武士と農民の身分の区別（兵農分離）を進めた。

ねらい：土地・年貢・身分を全国共通の基準で把握し、統一政権の土台をつくる。

外国との関係 禁教と朝鮮出兵

1587年 バテレン追放令：宣教師の国外退去を命じる。ただし南蛮貿易は利益が大きく、貿易そのものは続けた。

文禄・慶長の役：明の征服を目指し、1592年と1597年に朝鮮へ出兵。朝鮮水軍や明軍とも戦い、朝鮮半島に大きな被害を与えた。1598年の秀吉の死後、日本軍は撤兵。

1600〜1615 家康が支配を確立

  1. 1600年 関ヶ原の戦い：家康の東軍が、石田三成らの西軍に勝利。
  2. 1603年：家康が征夷大将軍となり江戸幕府を開く。1605年に将軍職を秀忠へ譲り、世襲を示す。
  3. 1614・1615年 大坂の陣：豊臣秀頼を滅ぼし、全国支配を確立。
  4. 1615年：武家諸法度などを定め、大名・朝廷への統制を整える。

江戸初期 家康の積極外交と、その後の禁教

朱印船貿易
幕府の許可証である朱印状を与え、東南アジアと交易。各地に日本町が成立。

欧州との通商
オランダ・イギリスに通商を許可。漂着したウィリアム＝アダムズ（三浦按針）も家康に仕えた。

禁教へ
1612年に幕府領、1614年に全国へキリスト教禁止を拡大。宣教師・信者を国外へ追放。

1613年、仙台藩主伊達政宗は慶長遣欧使節（支倉常長）をメキシコ・スペイン・ローマへ派遣した。

なぜ統一権力は宗教と対立したのか

信長 × 仏教勢力
寺社や一向一揆は、多数の信者、武力、土地、通行・商業上の権益をもち、大名から自立した政治勢力でもあった。信長は全国統一と流通支配を妨げる勢力として戦った。キリスト教は南蛮貿易と結びつき、仏教勢力への対抗にもなるため保護した。

秀吉 × キリスト教
はじめは布教を認めたが、九州平定後、キリシタン大名と宣教師の強い結びつきや、布教が統一支配を妨げる可能性を警戒した。そこでバテレン追放令を出す一方、利益の大きい南蛮貿易は続けた。

家康・幕府 × キリスト教
はじめは貿易を優先したが、信者の結束、宣教師とスペイン・ポルトガル勢力との結びつきを警戒。幕府への服従を全国で徹底するため禁教を強め、のちの鎖国体制へつなげた。

共通点：宗教そのものだけでなく、「幕府・統一政権とは別の命令系統や大きな組織力をもつ勢力」を支配上の問題と見た。

周辺エピソード｜お市の方がつなぐ三つの時代

信長の妹お市の方は近江の戦国大名・浅井長政と結婚したが、浅井氏は信長と対立。1573年に浅井氏が滅ぶと、お市と三人の娘は織田方へ戻った。のちにお市は柴田勝家と再婚し、1583年の賤ヶ岳の戦い後、北ノ庄城で勝家とともに死去した。

茶々（淀殿）秀吉の側室・秀頼の母 初京極高次の妻 江徳川秀忠の妻・家光の母

三姉妹の人生は、織田家・豊臣家・徳川家を結び、統一政権の移り変わりそのものと重なる。

統一三者の違い： 信長＝統一を開始・旧勢力を打破／秀吉＝全国統一・検地と刀狩／家康＝幕府を開き、豊臣氏を滅ぼして長期支配の仕組みを整備。

4｜幕府が管理した対外関係とその転換

「鎖国」体制から開国へ

4 / 4

「鎖国」は外国との交流をすべて断つ政策ではありません。幕府が相手・港・貿易量・情報を限定し、対外関係を独占的に管理する体制です。

1616〜1641 鎖国体制ができるまで

  1. 1616年 ヨーロッパ船の来航地を平戸・長崎に制限。
  2. 1624年 スペイン船の来航を禁止。
  3. 1633年 奉書船以外の海外渡航を禁止。
  4. 1635年 日本人の海外渡航と帰国を禁止。
  5. 1637〜38年 島原・天草一揆。重い年貢やキリスト教弾圧などが背景。
  6. 1639年 ポルトガル船の来航を禁止。
  7. 1641年 オランダ商館を平戸から長崎の出島へ移す。
目的：キリスト教の禁止、海外貿易の統制、貿易利益と海外情報の幕府による独占、大名が外国と結びつくことの防止。

江戸時代 交流を続けた「四つの口」

長崎口
オランダ・中国（清）
貿易と海外情報。西洋の学問は蘭学へ。
対馬口
朝鮮
対馬藩の宗氏が外交・貿易を担当。朝鮮通信使も来日。
薩摩口
琉球王国
1609年に薩摩藩が侵攻。琉球は中国との冊封関係も保った。
松前口
アイヌ
松前藩が蝦夷地で交易を管理。交易をめぐる対立も起きた。

交流の成果 蘭学と海外情報

オランダ語を通して西洋の医学・天文学などを学ぶ蘭学が発達。杉田玄白・前野良沢らは1774年に『解体新書』を出版した。

長崎のオランダ商館長が提出するオランダ風説書は、幕府が海外情勢を知る重要な手段だった。「鎖国」下でも知識と情報は入っていた。

18世紀末〜1842 外国船が近づく

1792ロシア使節ラクスマンが根室に来航し、通商を求める。

1804ロシア使節レザノフが長崎に来航するが、幕府は通商を拒否。

1808イギリス軍艦によるフェートン号事件。長崎警備の弱さが表面化。

1825異国船打払令。接近した外国船を武力で追い払う方針。

1837モリソン号事件。日本人漂流民を送り届けようとしたアメリカ船を砲撃。

1840〜42清がアヘン戦争でイギリスに敗北。幕府は危機感を強める。

1842薪水給与令。外国船に燃料・水を与え、穏便に退去させる方針へ緩和。

1853〜1858 ペリー来航と開国

1853年

アメリカ東インド艦隊司令長官ペリーが浦賀に来航。大統領の国書を渡し、開国を要求。

1854年

日米和親条約。下田・箱館を開き、漂流民の救助・薪水食料の供給などを定める。日本は開国へ。

1858年

大老井伊直弼が日米修好通商条約に調印。本格的な貿易を開始。領事裁判権を認め、関税自主権がない不平等条約。

全4枚の流れを一息で

元寇後の不満 → 鎌倉幕府滅亡 → 室町幕府 → 応仁の乱 → 戦国時代 → 鉄砲・キリスト教 → 信長の統一事業 → 中国大返しで秀吉が主導権 → 秀吉の全国統一 → 関ヶ原で家康が勝利 → 江戸幕府 → 鎖国体制 → 外国船接近 → ペリー来航 → 開国

最重要注意： 「鎖国」＝完全な孤立ではない。長崎・対馬・薩摩・松前の四つの口で交流を続けつつ、幕府が対外関係を管理した。
